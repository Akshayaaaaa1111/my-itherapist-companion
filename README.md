🌿 iTherapist – AI-Powered Mental Wellness Chatbot

iTherapist is an AI-driven conversational assistant designed to provide emotional support, reflective listening, and structured guidance using modern NLP techniques and memory-based context retrieval.

🚀 Features
💬 Conversational AI therapist interface
🧠 Emotion-aware responses
🗂️ Memory system using vector database (ChromaDB)
🔁 Context-aware replies using RAG (Retrieval Augmented Generation)
⚡ FastAPI backend + React (Lovable) frontend
🔐 Session-based conversation tracking
🏗️ Tech Stack
Frontend
React (Vite)
Lovable (UI generation)
Backend
FastAPI
Python
AI / NLP
LLM API (Groq / LLaMA / OpenAI)
Sentence Transformers (all-MiniLM-L6-v2)
ChromaDB (vector storage)
